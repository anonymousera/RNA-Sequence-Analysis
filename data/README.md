# Data

This directory is a placeholder for the GSE206308 input files, which are not included in this repository. Download them from GEO and place them here before running `src/rna_seq_ana.py`:

- `control/c1.txt`, `control/c2.txt`, `control/c4.txt` — control samples
- `disease/pd1.txt`, `disease/pd2.txt`, `disease/pd4.txt`, `disease/pd5.txt` — Parkinson's disease samples

Each file is tab-separated with two columns (gene ID, count) and no header.
